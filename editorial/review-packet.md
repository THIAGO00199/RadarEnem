# ATENA · Caderno de revisão pedagógica independente

Aprovação humana pendente. Este inventário permite conferir cada aplicação no contexto, além da autoria. O hash vincula o parecer ao texto exato. Execute `npm run editorial:prepare` após alterações; pareceres de textos alterados voltam a pendente.
